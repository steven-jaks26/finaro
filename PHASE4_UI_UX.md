# Finaro Phase 4 — UI/UX

- Forecast-first Home hierarchy: current balance, risk, minimum future balance and trend are primary.
- Progressive disclosure: records live in Financial rather than cluttering Home.
- One clear primary action for adding a record.
- Native Persian RTL information hierarchy.
- Material 3 with semantic success/error colors and generous touch targets.
- NavigationBar on phones and a structure ready for larger screens.
- Calm visual language: neutral background, white surfaces, restrained borders, 12–26px radius scale.
- Money values are visually dominant and use grouped Toman presentation.
- Risk is explained in plain Persian rather than relying on color alone.
- Offline security is visible to build user trust.
